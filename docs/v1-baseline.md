# Базовые сценарии Bank API V1

Исходная версия зафиксирована тегом `v1.0.0` на коммите `eb1306f6`. Сравнение выполняется по внешним HTTP-маршрутам. Значения ID и времени зависят от окружения.

| Сценарий | Контрольный запрос и результат |
| --- | --- |
| Вход | `POST /api/auth/login` с полями `email`, `password` возвращает 200 и поля `accessToken`, `tokenType`, `expiresIn`. |
| Профиль | `GET /api/users/me` с Bearer возвращает профиль без пароля и хеша. |
| Счёт | `POST /api/accounts` возвращает 201 и созданный счёт с валютой RUB и балансом 0. |
| Карта | `POST /api/accounts/{id}/card` возвращает 201. У счёта может быть одна карта. |
| Пополнение | `POST /api/accounts/{id}/deposit` с `{"amount":120.00}` возвращает 200 и операцию типа DEPOSIT. |
| Снятие | `POST /api/accounts/{id}/withdraw` с `{"amount":20.00}` возвращает 200 и операцию типа WITHDRAWAL. |
| Перевод | `POST /api/accounts/{id}/transfer` с `{"amount":25.00,"destinationAccountNumber":"40817810000000000001"}` возвращает 200 и операцию TRANSFER. |
| Баланс и расходы | После пополнения 120, снятия 20 и перевода 25 на счёт другого пользователя балансы равны 75 и 25, расходы отправителя равны 45. |
| Доступ | Приватный маршрут без JWT возвращает 401. Клиент на административном маршруте получает 403. Чужой счёт возвращает 404. |

Проверка V1 на стенде разработки использовала 120 последовательных вызовов `GET /api/accounts/{id}` после 10 прогревочных запросов. p95 составил 28,18 мс, ошибок — 0. V1 запускалась как локальный процесс Java 21 с отдельным PostgreSQL в Docker. `tools/measure-read.ps1` использует тот же сценарий через Gateway.
